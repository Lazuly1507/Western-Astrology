# Roadmap — Web-only Western MVP
21/10/2026. M0/M1 tiếp tục từ kết quả có sẵn; không khởi động lại. Person-week là công sức, không cam kết lịch. Chưa duyệt triển khai.

| Milestone | Công sức kỹ thuật dự trù | Kết quả và gate |
| --- | ---: | --- |
| M0 — Scope migration | 0.5 tuần-người | Archive Tu Vi, web-only/Western scopes, skills và reference migration; không xóa lịch sử |
| M1 — Discovery/design/architecture | 2–3 | PRD/research/3 concept/prototype/decisions/architecture/costs; chủ dự án duyệt, hiện đang ở gate này |
| M2 — Deterministic engine | 4–7 | License quote, runtime spike, tz normalization, planets/angles/houses/aspects, known/unknown fixtures; reviewer chốt oracle/tolerance |
| M3 — Web MVP | 4–6 | Public SEO content, form/natal/Big3, auth/saved charts, Constellation SVG tối giản nếu duyệt; responsive/a11y |
| M4 — AI | 2–4 | Mock contract trước, evidence/tone eval, quota/privacy; real API chỉ sau duyệt model/budget/consent |
| M5 — QA/SEO/security/beta | 3–5 | Numerical/RLS/E2E/a11y/restore/performance checks; staging, hạn mức beta, rollback |
| M6 — Future only | Chưa định lượng | Premium, forecasting/transits, synastry, returns/progressions và advanced reports; PRD/business case riêng |

M0–M5 kỹ thuật 15.5–25.5; nội dung/chuyên gia thêm3–5 tuần-người. Không chạy M2 triển khai trước duyệt M1. Có thể nghiên cứu/benchmark được ủy quyền riêng nhưng không coi im lặng là duyệt.

Không Expo/RN/EAS/Maestro/native store pipeline. Shared auth/UI có thể tái dùng tương lai; các hệ thống riêng cần rules/data/contract độc lập, không triển khai module mở rộng hiện tại. Chi phí [ở đây](architecture/cost-estimates.md).
