# Tử Vi domain research

**Deprecated in this project on 2026-10-21.** Preserved for historical Tu Vi work only. The owner confirmed Western Astrology as the current domain. Do not activate for Western requests.

## Workflow

1. Identify the requested rule and school. Separate historical terminology, computational convention and interpretive claim.
2. Read [source-policy.md](references/source-policy.md) when collecting or comparing sources. This is an attributed MIT reference from Duan Digi, not a verified computational oracle.
3. Build a rule record containing `ruleId`, school, version, inputs, outputs, source author/edition/page or commit/path, license, and unresolved alternatives. Label a rule without inspected evidence as unverified.
4. Cover only the requested dependencies: Can Chi, Âm Dương, Ngũ Hành, Mệnh/Thân, the twelve palaces, chính tinh/phụ tinh, and đại hạn/tiểu hạn/lưu niên as applicable. Keep palace names distinct from their Earthly Branch positions.
5. For disagreement, record both rules, assumptions and a synthetic distinguishing example. Do not merge different schools into an undocumented hybrid or decide by repository popularity.
6. Hand the accepted computational rule and reproducible examples to `tuvi-chart-engine`; hand sourced meanings and limitations to `tuvi-interpretation`.

## Acceptance

- Every adopted rule is traceable to an inspected source and an explicit school/version.
- Contradictions, uncertain birth-time conventions, leap-month treatment, age counting and day boundaries are visible before calculation.
- A repository's README accuracy claim is not independent verification. No complete rule tables or validated charts are bundled with this skill.
- Cultural interpretation is distinguished from scientifically established information; source licensing permits any copied material.
